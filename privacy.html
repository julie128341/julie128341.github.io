プライバシーポリシー

このページは「YouTube 運営ツール」が Google のユーザーデータをどう扱うかを説明します。 このツールを使うのは、YouTube チャンネルの運営者本人だけです。

使う情報

  • 運営者自身の YouTube チャンネルの情報と、動画の情報（YouTube Data API）
  • 運営者自身のチャンネルの再生数・視聴時間・視聴維持率・流入経路などの数字（YouTube Analytics API）

使い道

運営者自身のチャンネルへの動画の投稿と、自分の動画がどう見られたかを調べて次の動画づくりに生かすことだけに使います。 広告や、ほかの目的には使いません。

保存する場所

取得した数字と認可の情報（トークン）は、運営者のパソコンの中にだけ保存します。 外部のサーバーには送りません。

第三者への提供

取得した情報を、第三者に提供したり販売したりすることはありません。

Google API サービスのユーザーデータに関するポリシー

このツールが Google API から受け取った情報の利用と他のアプリへの移転は、 Google API サービスのユーザーデータに関するポリシー （限定使用の要件を含む）に従います。

許可の取り消しと削除

このツールへの許可は、Google アカウントの サードパーティによるアクセスからいつでも取り消せます。 運営者のパソコンに保存した情報は、運営者がいつでも削除できます。

制定日：2026年10月14日

Privacy Policy (English)

This tool is used only by the owner of a YouTube channel, for the owner's own channels. It reads the owner's own channel and video information (YouTube Data API) and the owner's own channel analytics (YouTube Analytics API), and uploads videos to the owner's own channels. The data is used only for uploading videos and for analyzing how the owner's videos were watched. Retrieved data and authorization tokens are stored only on the owner's own computer and are not sent to any external server. The data is never shared with or sold to third parties. Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from Google Account third-party access.

Effective date: October 14, 2026
